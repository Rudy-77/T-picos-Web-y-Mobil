# Problema 1

Que lenguaje y que patrón de diseño usarían para hacer una aplicación tipo WhatsApp que me permita trabajar con LoRa.

**Idea base:** app de chat que en vez de usar la línea celular, use un módulo LoRa conectado al celular para enviar/recibir mensajes.

- **Lenguaje app:** Flutter, para poder usar la misma base en ambas plataformas.
- **Lenguaje del módulo:** C/C++, porque así se programan los módulos LoRa.

**Pasos básicos:**

1. Conectar el celular al módulo LoRa.
2. Escribir mensaje en la app.
3. Enviarlo por LoRa al otro dispositivo.
4. Mostrarlo en pantalla cuando llegue.

**Patrón de diseño base:** Observer, para que la app se entere y muestre el mensaje apenas llegue.

# Problema 2

Necesito reconocer con las cámaras de seguridad de una escuela cuántos espacios vacíos se tienen en el estacionamiento para poder utilizarlos, qué tecnología, qué lenguaje y qué patrón de diseño puedo utilizar. El objetivo es que me digan cuántos lugares libres hay.

**Idea base:** usar las cámaras ya existentes para "ver" cada espacio y detectar si hay auto o no.

- **Lenguaje:** Python, es el más usado para este tipo de tareas.
- **Tecnología clave:** OpenCV para procesar imagen + un modelo simple de detección YOLO o similar.

**Pasos básicos:**

1. Marcar en la imagen dónde está cada espacio.
2. Revisar cada espacio: ¿hay auto o no?
3. Contar los que están vacíos.
4. Mostrar el número.

**Patrón de diseño base:** Pipeline, para organizar el proceso en pasos simples y separados.
